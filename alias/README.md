# yf-git-log

Unscoped alias of [`@yourfam/yf-log`](https://www.npmjs.com/package/@yourfam/yf-log). Same command (`yf-log`), same version.

npm will not publish unscoped `yf-log` (too similar to existing `yflog`). This name is the `npx` stand-in.

```bash
npx yf-git-log --help
```

Install the scoped package if you can; this name exists so `npx yf-git-log` cannot be taken by someone else.
